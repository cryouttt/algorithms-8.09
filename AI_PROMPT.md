# Промт для ИИ на создание проекта Scratch

Ниже приведён промт, использованный для подготовки учебного проекта.

---

Разработай подробно проект в **Scratch 3.32.1** для визуальной и анимированной демонстрации алгоритма решения следующей задачи.

### Условие задачи

Имеется неупорядоченный массив из `n` различных целых чисел от `0` до `n`, при этом одно число `J` отсутствует:

`0, 1, ..., J-1, J+1, ..., n`.

Необходимо **за один цикл** определить недостающее число `J`.

### Требования к алгоритму

Используй способ через сумму элементов:

1. Вычислить сумму всех возможных чисел от `0` до `n` по формуле:
   `S_expected = n × (n + 1) / 2`.
2. За **один цикл** пройти по массиву и получить фактическую сумму его элементов `S_actual`.
3. Определить недостающее число:
   `J = S_expected - S_actual`.
4. Не использовать второй цикл и не использовать вложенные циклы для поиска числа.
5. Каждый элемент массива должен обрабатываться ровно один раз.

### Данные демонстрационного примера

Используй массив:

`0, 1, 2, 4, 5`.

Для него:

- `n = 5`;
- ожидаемая сумма = `15`;
- фактическая сумма = `12`;
- результат `J = 3`.

### Требования к Scratch

Создай:

- список `Массив`;
- переменную `n`;
- переменную `i`;
- переменную `СуммаФакт`;
- переменную `Сумма ожидаемая`;
- переменную `J`.

Первый индекс списка Scratch считать равным `1`.

Ключевой цикл должен соответствовать логике:

```text
повторить (n) раз
    взять элемент (i) списка [Массив]
    добавить его значение к [СуммаФакт]
    увеличить [i] на 1
```

После цикла:

```text
J = Сумма ожидаемая - СуммаФакт
```

### Требования к анимации

Проект должен выглядеть как небольшая учебная презентация, а не просто вычисление переменных.

Используй персонажа **Avery** или аналогичного персонажа-ведущего.

Сценарий анимации:

1. Начальная сцена — школа.
2. Персонаж появляется и говорит: «Здравствуйте! Меня зовут Соня. Я продемонстрирую решение задачи».
3. Персонаж кратко объясняет условие.
4. Сцена переключается на школьную доску.
5. На экране отображается исходный массив.
6. Персонаж объясняет формулу ожидаемой суммы.
7. Во время единственного цикла визуально показывать обработку элементов массива:
   - номер текущего элемента;
   - значение текущего элемента;
   - изменение фактической суммы после добавления этого элемента.
8. Сделать небольшую паузу между итерациями, чтобы зритель видел процесс обработки массива.
9. После завершения цикла вывести ожидаемую и фактическую суммы.
10. Затем вычислить и крупно показать итог: «Недостающее число J = 3».
11. Завершить сообщением: «Массив был просмотрен только один раз».
12. Допускаются смена костюмов, плавное перемещение персонажа и умеренное использование звуковых эффектов.

### Требования к ответу ИИ

Дай:

1. Полный сценарий проекта.
2. Точный перечень переменных и списков.
3. Пошаговую инструкцию по меню Scratch 3.32.1: какие категории и блоки выбирать.
4. Полную последовательность блоков от нажатия зелёного флага до вывода результата.
5. Отдельно покажи содержимое единственного цикла.
6. Объясни, почему алгоритм соответствует условию «за один цикл».
7. Проверь результат на массиве `[0, 1, 2, 4, 5]`.
8. Не заменяй алгоритм готовым ответом `J = 3`: число должно быть вычислено программой.
9. Если система умеет создавать файл Scratch `.sb3`, сформируй его. Если не умеет — дай достаточно точную структуру блоков, чтобы проект можно было собрать вручную без дополнительных уточнений.
