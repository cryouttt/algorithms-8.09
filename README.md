# Поиск недостающего числа за один цикл — Scratch 3.32.1

Учебный проект на **Scratch 3.32.1**, демонстрирующий визуальный алгоритм поиска одного недостающего числа в неупорядоченном массиве.

## Условие задачи

Имеется неупорядоченный массив из `n` различных целых чисел из диапазона от `0` до `n`. Одно число `J` отсутствует:

```text
0, 1, ..., J-1, J+1, ..., n
```

Необходимо определить недостающее число `J`, просмотрев массив **только за один цикл**.

## Идея решения

Сумма всех целых чисел от `0` до `n` вычисляется по формуле:

```text
S_expected = n × (n + 1) / 2
```

За один проход по массиву вычисляется сумма фактически присутствующих элементов:

```text
S_actual = a1 + a2 + ... + an
```

Недостающее число:

```text
J = S_expected - S_actual
```

Таким образом, каждый элемент массива обрабатывается ровно один раз.

## Пример в проекте

В Scratch используется массив:

```text
0, 1, 2, 4, 5
```

Количество элементов:

```text
n = 5
```

Ожидаемая сумма чисел от `0` до `5`:

```text
5 × (5 + 1) / 2 = 15
```

Фактическая сумма элементов массива:

```text
0 + 1 + 2 + 4 + 5 = 12
```

Результат:

```text
J = 15 - 12 = 3
```

Следовательно, недостающее число — **3**.

## Используемые данные Scratch

В проекте созданы:

- список `Массив`;
- переменная `n` — количество элементов массива;
- переменная `i` — индекс текущего элемента;
- переменная `СуммаФакт` — сумма элементов массива;
- переменная `Сумма ожидаемая` — сумма чисел от `0` до `n`;
- переменная `J` — найденное недостающее число.

## Единственный цикл

Ключевая часть алгоритма реализована одним циклом Scratch:

```text
повторить (n) раз
    изменить [СуммаФакт] на (элемент (i) из [Массив])
    изменить [i] на (1)
```

После завершения цикла выполняется:

```text
задать [J] значение ((Сумма ожидаемая) - (СуммаФакт))
```

Дополнительных и вложенных циклов для поиска недостающего числа нет.

Временная сложность алгоритма — **O(n)**.

## Визуализация

Проект оформлен как небольшая анимированная демонстрация:

1. Персонаж Avery появляется на школьной сцене и представляет задачу.
2. Сцена переключается на доску.
3. На экране демонстрируется исходный массив.
4. Объясняется вычисление ожидаемой суммы.
5. Массив последовательно обрабатывается одним циклом.
6. Вычисляется фактическая сумма.
7. На экране выводится найденное значение `J`.

В проекте используются смена фона, движение персонажа, реплики и звуковые эффекты.

## Запуск проекта

1. Установить или открыть **Scratch 3.32.1**.
2. Скачать файл [`project/missing-number.sb3`](project/missing-number.sb3).
3. В Scratch выбрать **Файл → Загрузить с компьютера**.
4. Открыть `missing-number.sb3`.
5. Нажать зелёный флаг.
